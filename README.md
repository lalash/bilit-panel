# bilit-panel

The server menu of Bilit Talaei. On a fresh Ubuntu server (as root):

```bash
bash <(curl -Ls https://raw.githubusercontent.com/lalash/bilit-panel/main/install.sh)
```

Then just `bilit-panel`:

- **Fresh server:** install prerequisites → install the site (online with a read-only token, or from an offline bundle file) → finish in the browser (web installer).
- **Installed server:** panel address and login, SSL, services, backups, Telegram, updates, offline bundle, restore.

This repository contains only the menu script. The site's code is private.
